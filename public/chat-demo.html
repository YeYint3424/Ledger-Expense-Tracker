Chat UI — mock data demo

This page uses fake in-memory data — no login, no server, no MongoDB. Everything (sending, editing, deleting, forwarding, replying) is simulated entirely in your browser so you can see and test the real ChatUI module in isolation. Try hovering a message to see the action icons; edit/delete only appear on messages sent by whichever "viewing as" user is selected below.
